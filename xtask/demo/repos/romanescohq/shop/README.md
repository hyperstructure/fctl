# Romanesco's shop

The web shop at romanesco.farm: build a box, pick a delivery day, pay and manage
the subscription. Next.js, TypeScript and Stripe.

```sh
npm ci
npm run dev        # http://localhost:3000, against the platform's API on :8080
npm test           # unit tests (Vitest)
npm run e2e        # end to end (Playwright)
```
