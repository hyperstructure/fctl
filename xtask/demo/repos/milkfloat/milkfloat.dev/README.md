# milkfloat.dev

The website: the landing page, the docs (built from
[milkfloat/milkfloat](https://github.com/milkfloat/milkfloat)'s `docs/` at
its latest release) and the nightly benchmarks from
[milkfloat/bench](https://github.com/milkfloat/bench).

```sh
npm ci
npm run dev      # localhost:4321
npm run build    # dist/, which Pages serves
```
