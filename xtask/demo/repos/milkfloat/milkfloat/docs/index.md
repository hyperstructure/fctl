# milkfloat

milkfloat plans delivery rounds: which van visits which customer, in what
order, so that every delivery arrives in its window and the vans drive as
little as they can.

- [Getting started](getting-started.md): install it and plan a first round.
- [Capacities](capacities.md): crates, kilos and cold boxes at once.
- [Re-planning](replanning.md): plan the rest of the day from where the vans are.
- [The cost function](cost-function.md): what milkfloat minimises, and how to weigh it.
